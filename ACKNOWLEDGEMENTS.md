# Acknowledgements

Two bots inspired this project. Neither contributed code, assets or data; both shaped what this bot set out to do.

[Card Buddy](https://dillonzer.github.io/cardbuddy.html) by dillonzer showed which information a card reply should carry: the art first, then the set and number, the rules text, legality and both price sources. This project answers the same questions in its own way.

[d0nkeybot](https://d0nkey.top) by [HSGuru](https://www.hsguru.com/about) is a Hearthstone bot whose inline `[[card]]` syntax let a card be named mid-sentence and answered without a command. That trigger style is why this bot exists: the itch to type a card name into a running conversation and get the card there, plus Limitless and Cardmarket one press away once it has been called
