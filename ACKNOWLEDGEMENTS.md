# Acknowledgements

Card Buddy, a well-known Pokémon card Discord bot, showed which information a card reply should carry: the art first, then the set and number, the rules text, legality and both price sources. This project answers the same questions. No code, assets or data files from Card Buddy are used

The inline `[[card]]` syntax comes from Hearthstone bots such as d0nkeybot, which let a card be named mid-sentence and answered without a command
