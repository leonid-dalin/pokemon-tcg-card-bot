# Acknowledgements

Two bots inspired this project. Neither contributed code, assets or data

[Card Buddy](https://dillonzer.github.io/cardbuddy.html) by dillonzer influenced the card reply: artwork first, followed by the set and number, rules text, legality and both price sources

[d0nkeybot](https://d0nkey.top) by [HSGuru](https://www.hsguru.com/about) is a Hearthstone bot with inline `[[card]]` lookups. That syntax inspired this bot's message trigger, so people can ask for a card during a conversation. The reply also links to Limitless and Cardmarket
